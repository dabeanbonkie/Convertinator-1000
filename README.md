# Description
The Convertinator 1000 is a basic power supply that converts voltage from a USB-C (5V) to 1.2V, 3.3V, 12V & 24V, also featuring an output for 5V. It has the input as the USB-C and the outputs as dupont headers as its main use is for prototyping small cicuits and basic breadboarding.
